# AMPA REINO DE MURCIA
# 🏫 Web AMPA

Página web oficial para la gestión y comunicación del AMPA. Este proyecto incluye información sobre actividades, comunicación con familias, un asistente/chatbot integrado y soporte para funcionamiento offline (PWA).

---

## 🚀 Características principales

* **Información y Novedades:** Información actualizada sobre eventos, noticias y reuniones.
* **Asistente Virtual (Chatbot):** Sistema de consulta rápida para responder dudas frecuentes de las familias.
* **Soporte Offline (PWA):** Uso de Service Worker para permitir una navegación rápida y caché de contenidos principales.
* **Diseño Responsivo:** Adaptado para su correcta visualización en móviles, tablets y ordenadores.

---

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Hojas de estilo organizadas para el diseño y maquetación.
* **JavaScript (ES6+):** Lógica del cliente, integración del chatbot e interacción interactiva.
* **Service Workers & JSON:** Gestión de datos locales y funciones PWA.
